# 💜 Painel Bertha: Base Estratégica de Resultados e Transparência

> **Status do Projeto:** 🚀 Finalizado / Em Operação  
> **Cliente:** Ministério das Mulheres (Desenvolvido pela CGTI)  
> **Tecnologias:** Power BI, Power Apps (Integração de Hub), SharePoint, Figma  
> **Conceito:** Hub Centralizador de Transparência e Governança da Administração Pública.

---

### 📝 Visão Geral
O **Painel Bertha** é a solução definitiva para a fragmentação de dados governamentais. Ele foi concebido como um **Portal de Transparência Integrado**, oferecendo um ponto de acesso único e intuitivo para todos os painéis estratégicos do Ministério das Mulheres. Através de uma interface clicável e responsiva, gestores e servidores conseguem navegar por todos os setores da administração em um só lugar, eliminando a dispersão de links e informações.

### 📽️ Interface do Hub Principal (Navegação Centralizada)
*Design focado em UX (User Experience) para garantir que qualquer usuário acesse as informações de todos os setores com apenas um clique.*

### 💰 Eficiência e Sustentabilidade Digital
O projeto segue a diretriz de **custo zero de licenciamento adicional**, aproveitando ao máximo o ecossistema Microsoft 365 já disponível no Ministério:
* **Unificação de Acesso:** Consolida diversos dashboards de Power BI em uma interface única.
* **Segurança Nativa:** Controle de acesso baseado em perfis, garantindo que cada usuário visualize apenas o que lhe é permitido.

### 🛠️ Diferenciais Técnicos & Navegação por Setor

| Setor Disponível | Descrição do Conteúdo | Objetivo Estratégico |
| :--- | :--- | :--- |
| **Ministra e Assistência** | Painéis de agenda e resultados de assistência direta. | Transparência de Gestão. |
| **Secretaria Executiva** | Dados administrativos e fluxo de processos internos. | Eficiência Operacional. |
| **Secretarias (SENATP, SENEV, SENAEC)** | Indicadores finalísticos e políticas públicas específicas. | Monitoramento de Impacto. |

---

### 🎨 Experiência do Usuário (UI/UX)

#### 🖱️ Hub Clicável de Fácil Acesso
A arquitetura do Painel Bertha permite que o usuário selecione a área de interesse diretamente no menu visual. Ao clicar em um ícone, o sistema redireciona automaticamente para o painel de Power BI correspondente, mantendo a identidade visual unificada e a fluidez na navegação.

#### 🎨 Identidade Visual e Inclusão
O design utiliza elementos gráficos que representam a diversidade e a força da atuação do Ministério, aliados a uma interface *clean* que facilita a leitura de dados estratégicos.
